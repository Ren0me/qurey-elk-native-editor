# Записи

SPA для ведения списка записей и работы с query-запросами. На главном экране отображается таблица записей, а добавление выполняется через модальную форму с валидацией.

## Возможности

- Таблица записей на `material-react-table`: сортировка, фильтрация, пагинация и русская локализация.
- Добавление записи через модальное окно.
- Автоматическая генерация `code` из `name` и `category`: транслитерация имени и код категории, например `тест` + `human` → `human.test`.
- Выбор категории через `SelectAutocomplete` на базе MUI `Autocomplete`.
- Ввод тегов с добавлением по Enter или кнопке `+`; теги отображаются чипами и удаляются по клику.
- Редактор `query` без внешних редакторов: подсветка, подсказки ключевых слов Elasticsearch DSL, автозакрытие скобок и работа с отступами.
- Валидация формы через `yup` и `react-hook-form`.

## Поля записи

| Поле | Тип | Обязательное | Примечание |
| --- | --- | --- | --- |
| `name` | `string` | Да | Обычное текстовое поле |
| `category` | `{ name: string; code: string }` | Да | Варианты: `человек/human`, `животное/animal` |
| `code` | `string` | Да | Формируется автоматически из `name` и `category.code` в формате `category.code.translit(name)`, доступно только для чтения |
| `description` | `string` | Нет | Многострочное текстовое поле |
| `tags` | `string[]` | Да | Минимум один тег |
| `query` | `object` | Да | JSON-объект запроса |

Порядок полей в форме: `name` → `category` → `code` → `description` → `tags` → `query`.

### Валидация

- `name`, `code`, `category`, `tags` и `query` обязательны.
- `description` можно оставить пустым.
- Для `tags` требуется хотя бы один добавленный тег.
- `query` должен быть корректным JSON-объектом. Поддерживается также «ослабленный» JSON: ключи без кавычек и висячие запятые.
- Массивы и примитивы в `query` не принимаются.

## Редактор запросов

Поле `query` использует собственный plain-редактор на `textarea` с подсветкой через наложение слоёв.

- Enter добавляет новую строку и не отправляет форму.
- Tab добавляет отступ.
- `Ctrl+Space` открывает подсказки ключевых слов.
- Скобки, кавычки и квадратные скобки автоматически закрываются.
- Поддерживаются ключевые слова Elasticsearch DSL: `query`, `bool`, `must`, `filter`, `match`, `terms`, `range`, `aggs`, `sort` и другие.

```text

├── app/                     # Точка входа и корневой компонент
├── pages/
│   └── records/             # Страница со списком записей
├── features/
```

## Ограничения

- Записи хранятся только в состоянии React и пропадают после перезагрузки страницы.
- Редактирование и удаление записей пока не реализованы.
- Список категорий фиксирован в `src/features/record-form/model/categories.ts`.
- Backend и сохранение данных отсутствуют.
